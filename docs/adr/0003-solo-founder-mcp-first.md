# ADR 0003: Solo-Founder MCP-First Product Model

## Status

Accepted

## Decision

FAIOS will start as a solo-founder SaaS rather than a workspace-based team platform. The founder is the only required FAIOS user in the MVP. The product will focus on voice/chat command execution through MCP-backed integrations.

## Rationale

The product promise is founder leverage: save time by making multiple startup tools accessible through natural language. Workspace memberships, team roles, and internal collaboration features add complexity without improving the first-order founder command loop.

## Consequences

The core model uses founder ownership instead of tenant/workspace ownership. Future team features can be introduced later as a separate product phase, but they must not distort the MVP command architecture.
